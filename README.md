🚀 استقرار هوشمند 3x-ui روی Railway (همراه با Nginx و CDN)
این مخزن شامل اسکریپت‌ها و فایل‌های پیکربندی برای راه‌اندازی خودکار و بهینه پنل 3x-ui روی پلتفرم Railway است. این پروژه به گونه‌ای طراحی شده که همیشه آخرین نسخه منتشر شده از پنل را دانلود کرده و با استفاده از Nginx به عنوان Reverse Proxy، ترافیک را از پشت شبکه‌های توزیع محتوا (مانند Cloudflare و ArvanCloud) با حفظ Real-IP مدیریت کند.
✨ ویژگی‌های کلیدی
🔄 آپدیت خودکار: در هر بار بیلد (Build) شدن داکر، آخرین نسخه (Latest Release) از گیت‌هاب MHSanaei/3x-ui دریافت و نصب می‌شود.
🛡️ پشتیبانی از Real-IP: تنظیمات کامل real_ip_header در Nginx برای شناسایی IP واقعی کاربران پشت پروکسی‌های کلادفلر و آروان‌کلاد.
🔀 مدیریت یکپارچه پورت‌ها: تمام مسیرها (پنل، ساب‌لینک و ۵۰ اینباند اختصاصی) تنها از طریق یک پورت عمومی (پورت ۳۰۰۰ داخلی Railway) در دسترس هستند.
🐳 ایمیج سبک: مبتنی بر Alpine Linux برای کاهش مصرف منابع و افزایش سرعت بوت.

🛠 راهنمای استقرار روی Railway
۱. آپلود فایل‌ها
فایل‌های Dockerfile، start.sh و nginx.conf.template را در یک مخزن گیت‌هاب (GitHub Repository) قرار دهید و آن را به Railway متصل کنید (یا مستقیماً از طریق Railway CLI دیپلوی کنید).
۲. تنظیمات Network در Railway
از آنجایی که Nginx در این کد روی پورت 3000 گوش می‌دهد، باید به Railway بگویید که ترافیک عمومی را به این پورت هدایت کند:
به بخش تنظیمات سرویس در Railway بروید.
در قسمت Networking -> Public Networking، یک دامنه تولید کنید (Generate Domain).
مطمئن شوید که در تنظیمات متغیرهای محیطی (Variables)، اگر متغیری به نام PORT وجود دارد، مقدار آن روی 3000 تنظیم شده باشد (هرچند در start.sh پورت 3000 هاردکد شده است).
۳. تنظیمات دامنه و CDN (کلادفلر / آروان‌کلاد)
دامنه خود را به آدرس Public که Railway داده است (CNAME) متصل کنید.
وضعیت پروکسی (ابر نارنجی): باید روشن باشد.
سطح SSL/TLS: در پنل CDN خود، حالت SSL را روی Full یا Full (Strict) قرار دهید. (هرگز روی Flexible نگذارید، زیرا باعث ریدایرکت‌های بی‌نهایت می‌شود).

⚠️ هشدار بسیار مهم: پایداری دیتابیس (Data Persistence)
پلتفرم Railway یک محیط Ephemeral (موقتی) است. این بدان معناست که با هر بار Restart شدن کانتینر یا Deploy جدید، دیتابیس SQLite پاک شده و تمام کاربران و تنظیمات شما از بین می‌رود!
💡 راه‌حل‌های پیشنهادی:
استفاده از Railway Volumes (پیشنهاد اول):
در پنل Railway، یک Volume جدید بسازید.
آن را به مسیر /usr/local/x-ui/ (یا مسیری که فایل x-ui.db در آن ذخیره می‌شود) در کانتینر Mount کنید.
استفاده از دیتابیس خارجی:
در تنظیمات Environment Variables، متغیرهای اتصال به MySQL یا PostgreSQL را اضافه کنید تا پنل به جای SQLite از یک دیتابیس ابری (مثل Supabase یا Clever Cloud) استفاده کند.
⚙️ تنظیمات اولیه پس از نصب
به آدرس https://your-domain.com/managepanel/ بروید.
در بخش تنظیمات پنل (Panel Settings):
Port را روی 2053 قرار دهید.
Web Base Path را روی /managepanel/ تنظیم کنید.
در بخش Subscription Settings:
Port را روی 2096 قرار دهید.
Path را روی /sub/ تنظیم کنید.
برای ساخت اینباند جدید، پورت‌ها را روی اعداد تعریف شده در nginx.conf (مثل 8002, 8003 و...) ست کنید و در تنظیمات کلاینت (V2Ray/XRay)، مقدار Host را روی دامنه خود و Path را روی /inX (مثلاً /in2) قرار دهید.
